## 已实施职责

| 所有者 | 职责与约束 |
| --- | --- |
| RootTabHost | 稳定保留最多四个按需创建的导航栈；active、prepared、inactive 分开。预览不能取得播放器、历史、草稿或云端写入权限。 |
| TabPageMotion | 按钮与根页边缘使用同一 RootFlight；目标不可用时有界等待或中止，不能绕过动画直接改选择。键盘先退出并稳定几何，再捕获画面。 |
| PageBodyHandoff | 正文跟手、松手补完／回弹、实际帧交接；固定栏独立于正文。透明时间线顶栏下的媒体带与正文同向移动。 |
| HeaderHandoff / NativeHeaderMotion | 固定上沿、下沿伸缩和内部控件替换；超时仅中止视觉，不报告导航成功。 |
| PresentationLifecycle / PageReturnCommit | requested 与实际 mounted 分开；导航结果与视觉结果分开。本地草稿只消费真实成功返回，云端仍明确确认。 |
| PageEdgeReturn | 子页两侧返回适配；边缘手势不重复播放第二次正文淡换或位移。 |

时间线边缘仍按原有上下区域切来源／媒体；其余根页边缘循环切主页面。作者榜、作者页、收藏中央横划切栏，子页边缘返回。配置页不把分段选择解释成浏览切栏。

界面方面，下载管理合并为任务／空间两栏；空间不再重复文件列表。下载设置补恢复默认。屏蔽作者复用序号标签，作者页只保留简短屏蔽提示，解除入口留在设置。关注列表使用账号绑定、有上限和过期规则的本地缓存，刷新失败保留已显示结果，数量放在列表末尾。
